# omd

Домашнее задание по базовому Python: задачи на множества, списки и словари.

## Требования

- Python 3.12 или новее

## Установка зависимостей

Внешние библиотеки не требуются, дополнительно ничего устанавливать не нужно.

## Запуск

    python omd.py

В Windows, если команда `python` не найдена, используй `py omd.py`.

Программа печатает результаты всех задач в stdout.
