# omd

Домашнее задание по базовому Python: функции.

## Требования

- Python 3.12 или новее

## Установка зависимостей

Внешние библиотеки не требуются, дополнительно ничего устанавливать не нужно.

## Запуск

    python functions.py

В Windows, если команда `python` не найдена, используй `py functions.py`.

Программа печатает результаты всех задач в stdout.
