# Анализ данных о Нобелевских лауреатах

## Описание проекта

В этом проекте проводится анализ данных о лауреатах Нобелевской премии с помощью Python.

Основные задачи:

- загрузка и обработка данных

- проверка пропусков и идентификаторов лауреатов

- анализ распределения лауреатов по странам и категориям премий

- анализ возраста получения первой премии

- сравнение количества мужчин и женщин среди лауреатов

- анализ изменения показателей по десятилетиям

## Данные

Данные загружаются с помощью библиотеки requests через Nobel Prize API:

https://api.nobelprize.org/2.1/laureates?limit=1200

## Файлы проекта

- aggregations.py - функции для расчёта среднего, медианы, минимума, максимума и получения топ-N элементов

- atribute_manager.py - добавление новых атрибутов

- dataset_helpers.py - подсчёт пропусков, фильтрация, группировка и агрегация данных

- json_dict_processing.py - обработка вложенных словарей

- laureates_configs.py - конфигурации для обработки данных о людях и организациях

- prizes_configs.py - конфигурация для обработки данных о премиях

- laureates_countries_task__8_ (1).ipynb - основной ноутбук с анализом данных и выводами

- tests - папка с тестами написанных функций

- requirements.txt - список зависимостей

## Установка

Используемая версия Python - 3.12.10

Для запуска проекта нужно перейти в папку final_nobel, создать виртуальное окружение и установить библиотеки

Команды для Windows (Git Bash):

```

python -m venv .venv

source .venv/Scripts/activate

python -m pip install -r requirements.txt

```

## Запуск

Открыть ноутбук laureates_countries_task__8_ (1).ipynb в VS Code, выбрать созданное виртуальное окружение и запустить все ячейки.

Для загрузки данных нужен интернет.

## Запуск тестов

```

python -m pytest tests -v

```
